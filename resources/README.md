# 14 - Resources

## Overview

This folder contains curated learning resources for analytics engineering, data engineering, analytics, and modern data platforms.

The purpose of this collection is to provide a structured path from beginner fundamentals to advanced professional-level skills.

Resources are organized into:

- Books
- Courses
- YouTube channels
- Official documentation
- Blogs and newsletters
- Practice platforms
- Datasets
- Communities

---

# Learning Philosophy

Becoming an excellent analytics engineer requires combining:

```
Theory

+

Hands-On Practice

+

Real Projects

+

Community Learning

+

Continuous Improvement
```

Avoid only consuming tutorials.

The goal is to build:

- Technical depth
- Problem-solving ability
- Production experience
