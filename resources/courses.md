# Courses For Analytics Engineering, Data Engineering, And Modern Data Platforms

## Overview

Courses provide structured learning paths for developing practical skills in analytics engineering and data engineering.

A strong analytics engineer should build expertise across:

- SQL
- Python
- Data modeling
- Analytics engineering
- dbt
- Data warehouses
- Cloud platforms
- Data pipelines
- Testing and reliability

This resource list is organized from beginner to advanced.
