# Recommended Books For Analytics Engineers

## Overview

Books provide the theoretical foundation needed to become an exceptional analytics engineer.

While tools change frequently, strong fundamentals in:

- Data modeling
- Databases
- Software engineering
- Distributed systems
- Analytics
- Cloud architecture

remain valuable throughout your career.

This list is organized from foundational to advanced.

---

# Level 1: SQL And Database Foundations

---

# 1. SQL for Data Analysis

## Author

Cathy Tanimura

---

## Why Read It

This book focuses on using SQL to answer real analytical questions.

It teaches:

- Filtering data
- Aggregations
- Joins
- Window functions
- Analytical thinking

---

## Key Topics

```
SELECT

WHERE

GROUP BY

JOINs

CTEs

Window Functions

Time Analysis

Customer Analysis
```

---

## Best For

- Data analysts
- Analytics engineers
- BI engineers

---

# 2. Learning SQL

## Author

Alan Beaulieu

---

## Why Read It

A beginner-friendly introduction to SQL fundamentals.

Covers:

- Database concepts
- Query writing
- Data manipulation
- Advanced SQL features

---

## Best For

Beginners building database foundations.

---

# Level 2: Data Modeling

---

# 3. The Data Warehouse Toolkit

## Authors

Ralph Kimball and Margy Ross

---

## Why Read It

One of the most important books in analytics engineering.

It introduces dimensional modeling principles used in modern warehouses.

---

## Key Concepts

```
Fact Tables

Dimension Tables

Grain

Star Schema

Slowly Changing Dimensions

Business Processes
```

---

## Why It Matters

Analytics engineers use these concepts when designing:

- dbt models
- Warehouse structures
- BI datasets

---

# Final Advice

Do not read books passively.

For every chapter:

```
Learn Concept

↓

Build Example

↓

Apply To Project

↓

Document Learning
```

The goal is not to finish books.

The goal is to develop the ability to design and build reliable analytics systems.
