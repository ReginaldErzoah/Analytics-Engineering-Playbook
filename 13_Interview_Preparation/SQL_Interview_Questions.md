# SQL Interview Questions For Analytics Engineers

## Overview

SQL is one of the most important skills tested in analytics engineering interviews.

Analytics engineers use SQL to:

- Transform raw data
- Build analytical models
- Create metrics
- Investigate business problems
- Validate data quality

Interviewers evaluate not only whether you can write queries, but whether you understand:

- Business logic
- Query efficiency
- Data relationships
- Analytical reasoning

# Question 1: Select All Customers

## Problem

Retrieve all customers from the customers table.

Table:

```
customers
```

Columns:

```
customer_id

name

email

country
```

---

## Solution

```sql
SELECT *

FROM customers;
```

---

## Concept Tested

- SELECT statement
- Reading tables

---

# Question 2: Filter Customers By Country

## Problem

Find customers from Ghana.

---

## Solution

```sql
SELECT *

FROM customers

WHERE country = 'Ghana';
```

---

## Concept Tested

- WHERE clause
- Filtering data

## Solution

# Question 10: Departments With More Than 50 Employees

## Problem

Find departments with more than 50 employees.

---

## Solution

```sql
SELECT

department,

COUNT(employee_id) AS employees

FROM employees

GROUP BY department

HAVING COUNT(employee_id) > 50;
```

# Section 4: JOIN Questions

---

# Question 11: Combine Customers And Orders

## Problem

Display customer names and their orders.

Tables:

```
customers

orders
```

---

## Solution

```sql
SELECT

c.name,

o.order_id

FROM customers c

JOIN orders o

ON c.customer_id = o.customer_id;
```

---

## Concept Tested

- INNER JOIN
- Relationships

---

# Question 12: Find Customers Without Orders

## Problem

Identify customers who have never purchased.

---

## Solution

```sql
SELECT

c.customer_id,

c.name

FROM customers c

LEFT JOIN orders o

ON c.customer_id = o.customer_id

WHERE o.order_id IS NULL;
```

---

## Concept Tested

- LEFT JOIN
- NULL filtering

---

# Question 13: Product Sales Analysis

## Problem

Display product names and total revenue.

---

## Solution

```sql
SELECT

p.product_name,

SUM(o.quantity * o.price) AS revenue

FROM products p

JOIN orders o

ON p.product_id = o.product_id

GROUP BY p.product_name;
```

# Question 14: Find High-Value Customers

## Problem

Find customers who spent more than $10,000.

---

## Solution

```sql
WITH customer_sales AS (

SELECT

customer_id,

SUM(amount) AS total_spend

FROM orders

GROUP BY customer_id

)

SELECT *

FROM customer_sales

WHERE total_spend > 10000;
```

---

## Concept Tested

- Common Table Expressions
- Query organization

# Section 6: Window Function Questions

---

# Question 15: Rank Customers By Revenue

## Problem

Rank customers based on total spending.

---

## Solution

```sql
SELECT

customer_id,

SUM(amount) AS revenue,

RANK() OVER(

ORDER BY SUM(amount) DESC

) AS rank

FROM orders

GROUP BY customer_id;
```

---

## Concept Tested

- Window functions
- Ranking

---

# Question 16: Running Total Revenue

## Problem

Calculate cumulative revenue over time.

---

## Solution

```sql
SELECT

order_date,

SUM(amount)

OVER(

ORDER BY order_date

) AS running_total

FROM orders;
```

---

# Question 17: Compare Monthly Revenue

## Problem

Compare revenue with previous month.

---

## Solution

```sql
SELECT

month,

revenue,

LAG(revenue)

OVER(

ORDER BY month

) AS previous_month

FROM monthly_sales;
```

## Problem

Find duplicate customers.

## Solution

# Question 19: Create A Clean Customer Model

## Problem

Transform raw customer data.

---

## Solution

```sql
SELECT

customer_id,

TRIM(first_name) AS first_name,

LOWER(email) AS email

FROM raw_customers;
```

# Question 22: Monthly Growth Rate

```sql
WITH monthly_sales AS (

SELECT

DATE_TRUNC('month', order_date) AS month,

SUM(amount) AS revenue

FROM orders

GROUP BY month

)

SELECT

month,

revenue,

(revenue -

LAG(revenue)

OVER(ORDER BY month))

/

LAG(revenue)

OVER(ORDER BY month)

AS growth_rate

FROM monthly_sales;
```

# Question 23: Customer Retention

## Problem

Find returning customers.

---

## Approach

Identify customers with purchases in multiple periods.

---

Example:

```sql
SELECT

customer_id,

COUNT(DISTINCT month) AS active_months

FROM customer_activity

GROUP BY customer_id

HAVING COUNT(DISTINCT month) > 1;
```
